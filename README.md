# StudyTrack

StudyTrack is an Android application designed to help 
college students manage and track their assignments in 
one place.

## Features

- Add new assignments with subject, title, description, and due date
- Edit existing assignments
- Mark assignments as completed
- Delete assignments
- View total, completed, and pending assignment statistics
- Profile section for student information
- Loading, empty, and error states

## Tech Stack

- **Language:** Java
- **IDE:** Android Studio
- **UI:** XML, Material Design
- **Database:** Firebase Realtime Database
- **Local Storage:** SharedPreferences
- **Architecture Components:** Activities, Fragments, RecyclerView

## Project Structure

```text
com.example.studytrack
├── activities
├── fragments
├── adapters
└── models
```
## How to Run

1. Clone this repository.
2. Open the project in Android Studio.
3. Sync the Gradle files.
4. Run the application on an Android device or emulator.

## Purpose

StudyTrack was developed as an Android project to 
practice building a complete application with Firebase, 
RecyclerView, Fragments, CRUD operations, and Material-
based UI.
